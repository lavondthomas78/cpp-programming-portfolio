# Unit 9: Pointers and Dynamic Memory

## Overview
This collection of C++ labs demonstrates the use of pointers, dynamic memory allocation, dynamic arrays, sorting, and memory management.

## Labs

### Lab 9.1 — Pointer Variables
Demonstrates pointer variables by referencing rectangle dimensions, calculating area, and comparing values through pointers.

### Lab 9.2 — Dynamic Memory
Uses dynamically allocated integers and a character array, pointer arithmetic, user input, and proper memory deallocation.

### Lab 9.3 — Dynamic Arrays
Creates a dynamically allocated array for monthly sales values, then calculates the total and average sales.

### Lab 9.4 — Dynamic Scores and Sorting
Creates a dynamic array of test scores, validates input, calculates the average, and sorts the scores in ascending order using a bubble sort.

## C++ Concepts Demonstrated
- Pointers
- Dereferencing
- Dynamic memory allocation
- `new` and `delete`
- Dynamic arrays
- Pointer arithmetic
- Functions
- Input validation
- Bubble sort
- Memory management
