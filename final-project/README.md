# C++ Console Quiz Game

## Overview
This project is a console-based multiple-choice quiz game developed in C++ for CIS240 – Programming in C++. The application demonstrates fundamental programming concepts through an interactive quiz with randomized questions, input validation, scoring, and replay functionality.

## Features
- Main menu with Start, How to Play, and Exit options
- 10-question quiz bank
- Randomized question order using the Fisher-Yates shuffle
- User input validation
- Automatic score and percentage calculation
- Letter-grade calculation
- Play-again functionality
- Session high-score tracking

## C++ Concepts Demonstrated
- Variables and data types
- Arrays
- Structs
- Functions
- Loops
- Conditional statements
- Input validation
- Randomization
- Modular program design
